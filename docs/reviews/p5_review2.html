The Problem

Why Standard Cloud Deployment is Wasteful

Every major cloud provider cost calculator does the same thing: for each component, find the cheapest VM. Nobody looks at the bill for data flying between components on different clouds.

💸

Egress is Expensive and Ignored

GCP charges $0.12/GB to send data out. App tier (GCP) to DB (Azure) at 500 GB/month = $60/month in hidden costs - never shown in the VM picker dashboard.

📊

Cost Grows Linearly with Traffic

The greedy error compounds: at 10x traffic, it overpays by 43.9%. Greedy cost = $528, TEAP cost = $296 - a $231/month difference.

🔁

Direction Matters (Asymmetric Egress)

Azure egress = $0.087/GB vs GCP = $0.12/GB. If services MUST be on different clouds, putting the high-traffic sender on Azure saves 27% egress. No existing tool does this.

The Algorithm

TEAP - Traffic-aware Egress-Aware Placement

TEAP combines social network analysis (Louvain), operations research (ILP), and metaheuristics (local search). No prior paper combines all five phases for cloud placement.

1

Traffic Graph Construction

Build a weighted graph: nodes = components, edge weight = traffic x worst-case egress rate. Heavier edges = more expensive to separate across clouds.

2

Louvain Community Detection

Apply the Louvain algorithm from social network analysis to find clusters of tightly-communicating components. Components in the same cluster get co-located. First application of Louvain to cloud placement.

3

Egress-Asymmetry-Aware Assignment

Key insight: Azure=$0.087/GB, GCP=$0.12/GB. When clusters MUST be on different providers, put high-traffic senders on cheaper-egress providers. Sorts clusters by outbound traffic and providers by egress rate.

4

ILP Refinement on Reduced Search Space

Run ILP on cluster-to-provider assignment (P^K instead of P^N). 15 components / 4 clusters = solve 3^4=81 instead of 3^15=14 million combinations. Makes ILP tractable at any scale.

5

Component-Level Local Search

Try swapping each component to a different provider. Accept if cost reduces, repeat until no improvement. Catches edge cases where one component in a cluster has a different price profile from its peers.

Finding: ILP Refinement (Phase 4) is the critical phase

For Microservice Mesh, removing ILP refinement causes cost to jump 31.9%. Louvain clusters services correctly, but without ILP to refine cluster-to-provider assignment, the Phase 3 greedy assignment makes suboptimal choices. This validates that decompose-then-ILP beats clustering alone or full-scale ILP alone.
